## Annotations-Schema

 This page includes translations from the original source language in which the guide was authored. Information on these translations and instructions on how to provide feedback on the translations can be found [here](translationinfo.html). 

### Guideline Annotation Schema

The German page defines how a guideline recommendation is annotated: the YAML structure per recommendation, the data objects with their terminology, the FHIR mapping, and the meaning of the `mapping_quelle` values that mark how far a code has been validated (`leitlinie`, `mii-kds`, `standard`, `vorschlag`).

**English translation pending.** This page exists in German only for now. The guideline annotation is going through clinical validation first: the recommendations, the assigned terminology codes and the gap assessment may still change, and translating them now would mean re-translating them afterwards. The English version follows once the German content has been clinically confirmed.
