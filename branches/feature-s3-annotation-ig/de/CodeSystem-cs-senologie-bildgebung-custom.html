CodeSystem: CS Senologie Bildgebung Custom

: https://www.senologie.org/fhir/CodeSystem/bildgebung-custom : 0.10.0
Draft : CS_Senologie_Bildgebung_Custom

Custom Codes für radiologische Befunde der Senologie (LK-Status, Standort, Beurteilbarkeit, US-DEGUM) ohne passendes SNOMED-Mapping.

  • VS Senologie Beurteilbarkeit
  • VS Senologie LK-Status (Bildgebung)
  • VS Senologie Mikrokalk-Triage
  • VS Senologie Standort (intern / extern)
  • VS Senologie US-DEGUM Klassifikation

Profils: CRMI Shareable CodeSystem, CRMI Publishable CodeSystem

This case-sensitive code system https://www.senologie.org/fhir/CodeSystem/bildgebung-custom defines the following codes:
