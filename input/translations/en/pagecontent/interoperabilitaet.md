### Context

This Implementation Guide does not exist in isolation; it builds upon existing national and international specifications and is compatible with them. The following sub-pages describe compatibility with MII KDS, ISiK, and European standards in detail.

### Related Specifications

| Specification | Description |
|--------------|-------------|
| [MII KDS Onkologie](https://simplifier.net/medizininformatikinitiative-modulonkologie) | Core Data Set of the Medical Informatics Initiative (MII) for oncological data. Base profiles for diagnosis, TNM, therapy, and follow-up. This module inherits directly from it. |
| [MII KDS Pathologie](https://simplifier.net/medizininformatikinitiative-modulpathologie) | Pathology findings reports according to the MII specification. Foundation for DiagnosticReport and Specimen profiles. |
| [Breast Cancer Pathology Specification](https://bih-cei.github.io/BreastCancerSpec/) | An illustrative representation of a FHIR-based pathology report in the breast cancer context. Demonstrates how structured pathology can be modelled in FHIR. |
| [ISiK (gematik)](https://simplifier.net/isik) | Information Technology Systems in Hospitals (Informationstechnische Systeme im Krankenhaus). Base profiles for the German hospital context (Patient, Encounter, Condition, etc.). |
| [HL7 Europe Laboratory & Imaging](https://build.fhir.org/ig/hl7-eu/laboratory/) | European specification for laboratory and imaging findings. A potential syntactic foundation for structured imaging reports. |
| [mCODE (HL7 US)](https://build.fhir.org/ig/HL7/fhir-mCODE-ig/) | Minimal Common Oncology Data Elements. The US equivalent for basic oncological documentation on FHIR. |
| [International Patient Summary (IPS)](https://build.fhir.org/ig/HL7/fhir-ips/) | International patient summary. Relevant for cross-border care and EHDS compliance. |
| [oBDS (ADT/GEKID)](https://basisdatensatz.de) | Oncological Core Data Set (Onkologischer Basisdatensatz). XML-based reporting dataset for cancer registries in Germany. Target format of the oBDS StructureMaps. |
