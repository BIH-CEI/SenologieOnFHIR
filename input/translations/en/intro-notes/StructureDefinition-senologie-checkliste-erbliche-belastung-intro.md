This profile represents the structured documentation of the DKG checklist for identifying hereditary tumor predisposition (DKG items D24/D25) in breast cancer patients, capturing both whether the checklist was performed and, where applicable, the resulting risk score.

The profile constrains the FHIR `Observation` resource, which is the appropriate base for assessments and structured evaluations. A fixed SNOMED CT code (`445039002 — Assessment using risk assessment tool`) identifies the type of observation, ensuring consistent retrieval across systems. The `status` element is constrained to `#final`, reflecting the point-in-time nature of a completed checklist review.

Key must-support elements include: `code` (fixed to the risk-assessment SNOMED concept), `subject` (restricted to `Patient`), `effectiveDateTime` (the date the checklist was conducted), `valueBoolean` (D24 — whether the checklist was performed at all), and `component[score]` (D25 — an optional integer score component when a quantitative result is available). The `focus` element links to a `FamilyMemberHistory` resource, enabling traceability to the family history data that informed the assessment.

Within the breast cancer care pathway, this profile is applied during the initial diagnostic workup and tumor board preparation. It documents compliance with the S3 guideline and AGO recommendations on hereditary risk identification, and serves as the trigger for referral to genetic counseling or high-risk surveillance programs. Implementers should ensure that a corresponding `FamilyMemberHistory` instance is present when `focus` is populated.
