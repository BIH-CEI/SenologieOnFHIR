This profile represents the HER2 receptor status as determined by immunohistochemistry (IHC), a mandatory biomarker assessment performed on invasive breast carcinoma tissue to guide targeted therapy decisions — in particular, eligibility for HER2-directed agents and, under current guidelines, anti-HER2 antibody-drug conjugates for HER2-low disease.

The profile constrains the MII Oncology base profile `MII_PR_Onko_Mamma_Her2neu_Status`, which itself constrains the FHIR `Observation` resource. Inheriting from the MII parent ensures compatibility with the German national oncology data set (oBDS) and the MII core infrastructure. The parent already provides two value slices — an oBDS-aligned slice (positiv / negativ / unbekannt) and a guideline-aligned slice (`DefinitionLeitlinie`) — as well as a combined IHC-score plus ISH-result structure. This profile promotes the guideline slice to must-support and adds a `hasMember` link for ISH reflex testing.

**Key must-support elements:**

- `value[x].coding[DefinitionLeitlinie]` (MS): The guideline-based classification slice is the only slice that carries the full five-way HER2 spectrum — positiv, HER2-low (IHC 2+/ISH– or IHC 1+), HER2-ultralow (IHC 0 with faint incomplete staining), negativ, and equivocal. The oBDS slice alone cannot distinguish HER2-low from HER2-negative, making this slice essential for any HER2-low analytics or clinical trial eligibility checks.
- `hasMember` (MS): When IHC yields an equivocal result (score 2+), in-situ hybridisation (ISH) reflex testing is mandatory per current guidelines. This element carries a typed reference to the companion `MII_PR_MTB_INSITUHYBRIDIZATION_HER2` Observation, which records the quantitative ISH parameters (HER2/CEP17 ratio, signal counts, cell nuclei evaluated). Implementers must populate `hasMember` in all equivocal IHC cases and should surface the ISH result before reporting a final HER2 status.

**Scope boundary — what this profile does not cover:** Quantitative ISH parameters (ratio, copy numbers, counted nuclei) are intentionally out of scope here; they are modelled in the separate MII MTB ISH profile (LOINC panel 74885-5). Both profiles should be grouped under a common `DiagnosticReport` or linked via `hasMember` so that downstream systems receive the complete HER2 work-up in a single retrievable unit.

Within the breast cancer care pathway, this profile belongs to the pathology biomarker layer and is produced at initial diagnosis and at re-biopsy (disease progression or metastatic setting). It feeds therapy planning, tumour board documentation, and cancer registry reporting. Systems consuming this profile should resolve the `hasMember` reference before rendering a final HER2 status, and should prefer the `DefinitionLeitlinie` slice when evaluating HER2-low eligibility criteria.
