This profile represents the Ki-67 proliferation index as determined by immunohistochemical staining of breast tumor tissue, expressed as the percentage of Ki-67-positive tumor cells.

The profile constrains the FHIR `Observation` resource. `Observation` is the appropriate base resource because the Ki-67 index is a quantitative laboratory measurement derived from pathological examination; its value, date, and link to a patient must all be captured in a structured, computable form. No suitable Ki-67-specific profile exists in the MII Oncology module, so this profile follows the MII estrogen/progesterone receptor pattern — binding to a LOINC code and recording the result as a percentage `Quantity`.

Key must-support elements are `status` (fixed to `#final`, reflecting that only completed pathology reports are exchanged), `code` (fixed to LOINC `29593-1 — Cells.Ki-67 nuclear Ag/cells in Tissue by Immune stain`), `subject` (restricted to `Patient`), `effectiveDateTime` (date of immunohistochemical examination), and `valueQuantity` (the percentage value with UCUM unit `%`). The `specimen` element is available but not must-support, allowing implementers to reference the examined specimen when it is known.

Within the breast cancer care pathway this profile is used in the pathology report after surgical excision or core needle biopsy. The Ki-67 value is a key input to treatment decisions — in particular the selection of adjuvant chemotherapy versus endocrine-only regimens in hormone-receptor-positive, HER2-negative tumors — and is therefore exchanged between the pathology system, the tumor board, and the oncology treatment planning system.
