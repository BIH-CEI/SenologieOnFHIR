The **BIH Senologie Klinische Untersuchung** profile represents the findings of a physical breast examination performed per breast side as part of breast cancer assessment or follow-up care.

This profile constrains the FHIR `Observation` resource. The `Observation` resource is the natural fit because a clinical breast examination yields a structured set of findings — inspection, palpation, nipple assessment, skin changes, and lymph node status — each of which maps to an `Observation.component` slice. The top-level observation is anchored to LOINC code `32422-8` ("Physical findings of Breast") and is always recorded with `status = #final`.

Key must-support elements include `effectiveDateTime` (the date of examination), `bodySite` (constrained to the required value set `VS_Senologie_Seite` to distinguish left from right breast), and ten named `component` slices: `palpationsbefund`, `hautveraenderungen`, `mamillenbefund`, `lymphknotenstatus`, `inspektion`, `symmetrie`, `ptosis`, `klinisches-ct`, `klinisches-cn`, and `tumornachweis-status`. Each component carries a SNOMED CT code and restricts its value to `CodeableConcept` (and optionally `string` for free-text findings). The `klinisches-ct` and `klinisches-cn` components encode the examiner's clinical TNM staging estimate directly within the observation. Where findings differ between sides, separate `Observation` instances (one per side) are expected, with `bodySite` distinguishing them; within a single instance, the `observation-bodyPosition` extension on individual components may further differentiate laterality.

In the breast cancer care pathway this profile is used at initial presentation, during neoadjuvant therapy monitoring, and at surgical planning — wherever a structured, reproducible record of the physical breast examination is required alongside imaging and pathology findings.
