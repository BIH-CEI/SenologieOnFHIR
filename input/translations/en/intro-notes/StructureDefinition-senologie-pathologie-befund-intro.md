The **BIH Senologie Pathologie Befund** profile represents a completed surgical or biopsy pathology report for a breast cancer patient, capturing histopathological findings, specimen details, and the interpreting pathologist's overall assessment.

This profile constrains the `DiagnosticReport` resource via the MII Pathology Report (`MII_PR_Patho_Report`) parent profile. Grounding the report in `DiagnosticReport` allows structured linkage between the ordering encounter, the physical specimen, granular observation results (receptors, histology grade, B3 lesions), and the free-text conclusion — without scattering report-level metadata across custom extensions. The status element is fixed to `#final`, reflecting that only fully signed-out reports are exchanged.

Must-support elements include `category` (pathology/histopathology discipline), `code` (type of examination), `subject` (patient reference), `effectiveDateTime` (specimen collection date, mapped to `Pathologie.DatumEntnahme`), `issued` (report release date), `performer` (pathology institute or reporting pathologist, superseding the former `PathologyLab` extension), `specimen` (reference to `Senologie_Pathologie_Praeparat`, which carries specimen type, laterality, clock-face position, and nipple distance), and `result` (sliced grouper references to receptor status observations — ER, PR, HER2, Ki-67 — as well as histology and B3-lesion findings). The `conclusion` element holds the pathologist's free-text overall assessment.

Within the breast cancer care pathway this profile sits immediately downstream of surgery or biopsy: it aggregates the specimen and observation profiles into a single transmissible report that feeds staging, multidisciplinary tumour board discussions, and treatment planning. Implementers assembling a complete pathology bundle should populate the `specimen` reference with a conformant `Senologie_Pathologie_Praeparat` instance and the `result` references with the relevant receptor and histology observation profiles defined in this implementation guide.
