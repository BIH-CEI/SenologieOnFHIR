This profile represents a diagnostic imaging report for non-mammary imaging procedures performed in the context of breast cancer staging or follow-up, such as bone scintigraphy, CT, PET-CT, chest X-ray, or liver ultrasound.

The profile constrains the FHIR `DiagnosticReport` resource to capture structured findings from these supplementary modalities. Unlike dedicated mammography profiles, this profile does not restrict imaging modality to a fixed set — the specific modality is conveyed through open-coded `code.coding` slices supporting both LOINC and SNOMED CT, with the concrete values driven by the associated questionnaire form. The `category` element is fixed to `RAD` (Radiology) to ensure consistent retrieval across modalities, and `status` is constrained to `#final` to indicate a completed, signed-off report.

Must-support elements include `status`, `category`, `code` (with LOINC and SNOMED CT coding slices), `subject` (mandatory reference to `Patient`), `effectiveDateTime` (examination date), `resultsInterpreter`, `conclusion` (free-text narrative summary), `conclusionCode` (encoded finding such as metastasis suspected yes/no), and `result` (references to structured `Observation` resources for individual findings). An extension (`examinationLocation`) captures the physical site where the imaging was performed.

Within the breast cancer care pathway, this profile sits in the staging and disease monitoring phase alongside the dedicated mammography and ultrasound profiles. It is intended for use wherever a systemic imaging result — rather than a local breast assessment — must be recorded and exchanged, enabling complete oncological staging documentation within a single Implementation Guide.
