This profile records the progesterone receptor (PR) status of an invasive breast tumor, as determined by immunohistochemistry, and extends that result with the German-standard IRS (Immunoreactive Score, Remmele-Stegner) and the internationally used Allred Score to support PR-low analysis and cross-system interoperability.

The profile constrains the MII Oncology parent profile `MII PR Onko Mamma Rezeptorstatus Progesteron`, which itself derives from `Observation`. That parent already provides oBDS-aligned slicing for proportion of positive cells and staining intensity; this profile inherits all of those constraints and adds two further `component` slices rather than re-profiling from scratch. Using `Observation.component` for the composite scoring values keeps the entire PR result — guideline classification, cell fraction, staining intensity, IRS, and Allred Score — within a single Observation instance, avoiding the need for separate linked resources.

Must-support elements introduced or elevated by this profile are: `value[x].coding[DefinitionLeitlinie]`, which carries the guideline-defined classification of *positiv*, *gering-positiv*, or *negativ* (the three-way split is relevant for PR-low workflows per current AGO/S3 guidance); `component[irsScore]`, a `Quantity` with UCUM unit `{score}` representing the IRS product score (0–12, German standard); and `component[allredScore]`, a `Quantity` with UCUM unit `{score}` representing the Allred composite score (0–8, international). Both score components are optional (0..1) but must be supported by conformant systems. LOINC 85339-0 is noted as an alternative coding for the Allred Score on the PR component.

Within the breast cancer care pathway, this profile is populated from the pathology report at the time of primary diagnosis or after neoadjuvant therapy. Its output contributes to adjuvant endocrine therapy eligibility decisions alongside ER status, and feeds PR-low subgroup analyses. The profile maps to `Pathologie.BefundInvasiv.Biomarker.PR` in the BIH Senologie logical model and is intended as a backport candidate for a future release of the MII Oncology module.
