This profile represents a malignant breast tumor diagnosis — covering invasive carcinoma (ICD-10 C50) and ductal carcinoma in situ (D05) — as recorded at initial diagnosis and reported to the cancer registry.

The profile constrains the FHIR `Condition` resource via the German Medical Informatics Initiative (MII) oncology base profile `MII_PR_Onko_Diagnose_Primaertumor`. That parent profile already establishes oBDS-compliant (Onkologischer Basisdatensatz) structures for diagnosis verification (`verificationStatus`), date of first diagnosis (`extension[Feststellungsdatum]`), laterality (`bodySite`), and diagnostic evidence (`evidence.detail`). This profile adds breast-cancer-specific constraints on top without altering the inherited must-support obligations.

Key must-support elements specific to this profile are: `category[tumormanifestation]`, which classifies the tumor manifestation (primary tumor, locoregional recurrence, lymph node involvement, or distant metastasis) and allows multiple concurrent values; `code.coding[sct]`, bound to a curated ValueSet of 24 SNOMED CT breast-cancer concepts; and `stage`, which carries both the tumor grade (`stage.summary`) and a dedicated metastasis-stage slice (`stage[metastasis]`). An optional ICD-11 dual-coding slice (`code.coding[icd11]`) is provided for forward compatibility. All diagnosis codes additionally support a senologie-specific local coding system for center-internal granularity.

Within the breast cancer care pathway this profile is instantiated at the point of confirmed diagnosis — typically following histopathology — and is the anchor resource for downstream clinical data such as receptor-status observations, tumor staging, and treatment planning. Implementers integrating with German cancer registries should ensure that `verificationStatus` is populated according to the oBDS diagnosis-certainty vocabulary inherited from the parent profile.
