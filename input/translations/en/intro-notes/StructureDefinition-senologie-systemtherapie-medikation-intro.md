This profile represents a single administered dose of a systemic therapy agent in the context of breast cancer treatment.

The profile constrains `MedicationStatement` — specifically the MII Oncology parent profile `MII_PR_Onko_Systemische_Therapie_Medikation` — because systemic therapy administration in German oncology workflows is documented at the level of individual drug events rather than as a single aggregated record. Inheriting from the MII Oncology parent ensures compatibility with the German Medical Informatics Initiative (MII) core oncology module, including its ATC and UNII coding slices for the administered substance.

The following must-support elements are central to this profile: `status` (fixed to `#completed`, reflecting that only completed administrations are recorded), `medication[x]` with an extensible SNOMED CT slice bound to the senology-specific medication value set (supplementing the inherited ATC/UNII slices), `subject` (restricted to `Patient`), `dateAsserted`, `effective[x]` for the administration time window, `partOf` linking the individual dose back to the overarching systemic therapy `Procedure`, and `dosage.doseAndRate` carrying the administered dose. Two senology-specific extensions add cycle-level granularity: `therapyCycle` (cycle number, e.g. cycle 1, 2, 3) and `dayInCycle` (day within the cycle), which have no equivalent in the MII Oncology parent.

Within the breast cancer care pathway, this profile sits inside the systemic therapy module. One or more instances of this profile are referenced via `partOf` from a `SenologieSystemtherapieDurchfuehrung` procedure, collectively describing the complete regimen of a treatment cycle. It is intended for use wherever per-agent, per-administration traceability is required — for example, when documenting dose reductions, cycle delays, or substitutions during neoadjuvant or adjuvant chemotherapy, targeted therapy, or endocrine therapy courses.
