This profile represents the formal recommendation record produced by an interdisciplinary tumor board (Tumorkonferenz) for a breast cancer patient, capturing the consensus treatment plan agreed upon by the participating specialists.

The profile constrains the FHIR `CarePlan` resource because a tumor board recommendation is fundamentally a coordinated plan of care — not a single order or observation — whose structure naturally accommodates multiple concurrent therapy recommendations, a responsible patient, a linked diagnosis, and a defined planning period. `status` is fixed to `#active` and `intent` is fixed to `#plan` to reflect the authoritative, forward-looking nature of the document.

Must-support elements include `intent`, `title`, `description`, `subject` (Patient), `period.start` (the date the board convened), `category` (the type of board session, bound required to the MII Oncology `therapieplanung-typ` value set — pre-operative, post-operative, post-therapeutic, or therapeutic), `addresses` (the Condition that prompted the board), and `activity`. The `activity` backbone is open-sliced into twelve named recommendation categories — operative therapy, chemotherapy, radiotherapy, endocrine therapy, targeted therapy, immunotherapy, antiresorptive therapy, further diagnostics, further intervention, genetics (e.g. BRCA testing), clinical trial, and follow-up — each discriminated by a fixed SNOMED CT code on `activity.detail.code` and typed to the appropriate fulfillment resource kind (`ServiceRequest`, `MedicationRequest`, or `Appointment`).

In the breast cancer care pathway this profile sits at the conclusion of the diagnostic work-up phase and at the entry point of active treatment planning. It is intended to be exchanged alongside the staging and receptor-status profiles, providing downstream systems — scheduling, pharmacy, clinical trials recruitment — with a machine-readable record of the board's decisions.
