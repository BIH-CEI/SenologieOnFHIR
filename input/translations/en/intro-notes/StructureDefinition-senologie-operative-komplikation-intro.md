This profile represents a postoperative complication event in the context of breast cancer surgery, graded according to the Clavien-Dindo classification system.

The profile constrains the base FHIR `Observation` resource rather than `AdverseEvent`, following the pattern established by the German Medical Informatics Initiative (MII) for Clavien-Dindo-based complication recording. `Observation` provides a structured, codeable value slot for the complication grade (Grades I–V, SNOMED CT 1367519000–1367527009) and a `component` slice for the complication type, which `AdverseEvent` does not support as naturally. The `status` element is fixed to `#final`, indicating that only completed complication assessments are recorded.

Key must-support elements include: `code` (fixed to SNOMED CT 789279006 "Clavien-Dindo classification grade"), `valueCodeableConcept` (the assigned grade), `effectiveDateTime` (date the complication occurred), `method` (timing context: intraoperative, postoperative-inpatient, or postoperative-outpatient — replacing a former `ComplicationTiming` extension), `focus` (a reference to the `Procedure` that caused the complication), and the `component[komplikationsart]` slice (SNOMED-coded complication type, 0..1).

Within the breast cancer care pathway this profile anchors to the `Operation.Komplikation` node of the BIH Senologie Logical Model. Implementers populate it after a surgical procedure has been documented (see the corresponding Senologie Procedure profile) and link the two resources via the `focus` reference, enabling downstream quality reporting and registry submissions that require per-operation complication grades.
