[FAL] Aufnahmedatum

Datum der Aufnahme in die Gesundheitseinrichtung.
Bei einem ambulanten Eingriff entspricht das Aufnahmedatum dem Datum der Operation.
Bei einem stationären/teilstationären Eingriff ist hier das Datum der stationären/teilstationären Aufnahme zur Operation gemeint.
