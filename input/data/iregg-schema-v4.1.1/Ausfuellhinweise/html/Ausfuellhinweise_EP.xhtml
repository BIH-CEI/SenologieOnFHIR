OEP_ArtEingriffSchluessel Art dieses Eingriffs
Es wird unterschieden zwischen:
Ersteingriff
Bei einem Ersteingriff handelt es sich um den ersten endoprothetischen Eingriff an dem betroffenen Gelenk.
Folgeeingriff
Bei einem Folgeeingriff handelt es sich um einen Eingriff an einem Gelenk, an dem bereits ein endoprothetischer Eingriff stattgefunden hat.
